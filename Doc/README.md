# Projeto ColorChanger AI

## Descrição

Uma aplicação web que permite aos usuários carregar uma imagem de um ambiente (como um cômodo de uma casa) e alterar a cor de objetos específicos (paredes, móveis, etc.) clicando neles. Uma paleta de cores lateral oferece opções de pintura, e a alteração é visualizada em tempo real.

## Tecnologias Propostas

- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Framework UI (Opcional):** React.js ou Vue.js
- **Manipulação de Imagem:** HTML5 Canvas API
- **Segmentação de Imagem:** MediaPipe Image Segmenter (Google AI) ou OpenCV.js
- **Estilização:** CSS Modules ou Styled-Components (se usar React)

## Como Rodar o Projeto Localmente

1.  Clone o repositório: `git clone <URL_DO_SEU_REPOSITORIO>`
2.  Navegue até a pasta: `cd nome-do-projeto`
3.  Instale as dependências: `npm install`
4.  Inicie o servidor de desenvolvimento: `npm start`
5.  Abra [http://localhost:3000](http://localhost:3000 ) no seu navegador.
